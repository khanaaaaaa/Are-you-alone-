# Are You Human?

## What It Is

An interactive horror website disguissed as a cute little questionnaire. It starts off with simple questions and then a final queestion: **Are you human?**

## Why I Made It

I wanted to make something that starts off looking harmless and cute, the slowly makes you question everything. Basically I wanted to make something silly and unsettline at the same time.

## How I Made It

Tech Stack:

- HTML
- CSS
- JavaScript

I used mostly HTMML and CSS for the different scenes and navigation, and a little bit of JavaScript for the music. I tried to make the website use JavaScript but decided not to go with it fully because I just couldn't make it work T-T

The website uses URL hashes to move between each question, so every answe leads to another part of the story. Tried to implement other programming languages too and I couldn't bring my vision to life.

## What I Learnt And What I struggled With

The biggest challenge was getting all the different screens and glitch sections to work together. I also learnt a lot about CSS positioning (the hard way). The most fun was probably seeing the website actually work ang go from creepy to cute and vice versa.
